# Domeček aplikace

Interaktivní pomůcka pro neprogramátory: z čeho se skládá aplikace postavená s AI, co se stane po kliknutí a co si můžete postavit sami. Tři režimy: patra domu, animace toho, co se stane po kliknutí, a semafor rizika.

**Živě:** https://katerina-svi.github.io/domecek-aplikace/

## Ovládání

- Patra domu: klikněte na část domu nebo procházejte šipkami na klávesnici.
- Co se stane po kliknutí: vyberte scénář, další krok spustí šipka doprava nebo mezerník.
- Režim otevřete přímo z adresy: `#patra`, `#cesta`, `#semafor`.

Celé je to jeden soubor `index.html` bez závislostí, jen písmo Rubik se načítá z Google Fonts.
